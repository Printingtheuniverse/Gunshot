# Battle Arena

A starter online multiplayer arcade team-battle project.

## Run locally
1. Install Node.js.
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npm start`.
5. Open `http://localhost:3000` in two browser tabs to test multiplayer.

## Included
- Dashboard
- Player-name login/account placeholder
- Server browser
- Create/join server
- 2–4 team selection
- Game-mode voting
- Map voting
- Ready system and countdown
- Real-time multiplayer positions with Socket.IO
- Arcade-style click-to-tag scoring
- Team scoreboard

This is a prototype. The account system is intentionally a local player-name placeholder; production accounts should use a proper authentication provider and a database.
